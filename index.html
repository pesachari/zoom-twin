הקלט או העלה קטע הקשבה בפאנל כדי להתחיל

המצלמה השקטה שלי

זום רואה וידאו שלך שצולם מראש. המצלמה האמיתית נדלקת רק כשאתה מקליט.

1. קטע הקשבה (חובה)

את הקטע הזה רואים רוב הזמן: אתה יושב, מקשיב ומהנהן מדי פעם.

עוד לא הוקלט

2. קטע דיבור (מומלץ)

את הקטע הזה רואים כשאתה מדבר: פשוט דבר בטבעיות חצי דקה, על כל נושא.

עוד לא הוקלט

3. מיקרופון

מצב: מקשיב

הקו הלבן במד הוא סף הדיבור. כשאתה מדבר, הפס צריך לעבור אותו. כשאתה שותק, הוא צריך להישאר מתחתיו.

תצוגה

טיפים להקלטה שתיראה אמיתית
  • הקלט כשאין אף אחד מאחוריך, או כשאתה יושב מול קיר.
  • תאורה יציבה: אור יום מהחלון מולך, בלי מנורות שמהבהבות.
  • לבש את מה שאתה לובש בדרך כלל. אם תחליף לבגד שונה מאוד, כדאי להקליט מחדש.
  • בקטע ההקשבה: הסתכל על המסך, הנהן מדי פעם, ותסתכל לפעמים למטה כאילו אתה כותב. אל תיגע בפנים.
  • סיים את הקטע באותה תנוחה שבה התחלת, כדי שהמעבר בלולאה לא יורגש.
איך מחברים לזום
  1. מתקינים את OBS Studio (חינמי, מהאתר obsproject.com).
  2. פותחים את הדף הזה ב-Chrome, מפעילים מיקרופון ולוחצים H להסתרת הפאנל.
  3. ב-OBS: Sources ← + ← Window Capture ← בוחרים את חלון Chrome. אם החלון יוצא שחור, משנים את Capture Method ל-Windows 10 (1903 and up).
  4. ב-OBS לוחצים Start Virtual Camera.
  5. בזום: הגדרות ← וידאו ← מצלמה: OBS Virtual Camera.

חשוב: כש-Chrome מוסתר לגמרי מאחורי זום, הווידאו עלול לקפוא. השאר את החלון גלוי (במסך שני או בפינה), או הפעל את Chrome מקיצור דרך עם התוספת --disable-backgrounding-occluded-windows.
